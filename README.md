Team: Sumukh Gupta, Neya Tripathi, Aaditya Goel, Kushika Mishra, Eklavya Sharma. Instructor: Dr. Supriya Chanda.

## Problem

Classify a Hindi or Bengali YouTube / social-media comment by its stance toward the claim

> **"Climate change and global warming is a serious concern."**

| Label | Meaning |
|---|---|
| **Favour** | the comment agrees the claim is a serious concern |
| **Against** | the comment disagrees (denies, minimises, mocks the concern) |
| **None** | neutral, unrelated, or no clear stance |

Primary metric: **macro-F1**. Supporting: accuracy, per-class precision/recall, confusion matrix.

The task is derived from the **AISoMe 2026 shared task at FIRE 2026** (same claim, labels and languages). Its defining
property: **public training data is English; the test data is Hindi and Bengali.** That makes this a **cross-lingual
transfer** problem. We do not have the official dataset; all data below is what we built. See
[`docs/LITERATURE_REVIEW.md`](docs/LITERATURE_REVIEW.md).

## Reproduce Round 2 from scratch

```bash
python -m venv .venv && .venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu128   # RTX 50-series needs CUDA 12.8
pip install -r requirements.txt

python src/build_english_merged.py        # English GWSD + SemEval files (needs internet)
python src/make_splits.py                 # 1,750 / 309 / 349 English splits (asserted)
echo GEMINI_API_KEY=... > .env            # free key from aistudio.google.com/apikey (.env is git-ignored)
python src/generate_synthetic.py --run    # resumable; or --no-api to rebuild from data/synthetic/raw/*.jsonl
python -u src/run_all.py                  # translation + 8 runs (IndicBERT v2 C/A/B, TF-IDF A/B/C, MuRIL C/A), resumable
python src/evaluate.py                    # outputs/round2_results.md/.json, figures, error_examples.csv, README table
python src/make_report.py                 # docs/Round2_Progress_Report.docx (two A4 pages, numbers from the JSON)
python src/make_deck.py                   # outputs/Round2_Deck.pptx (and the Milestone 1 deck)
python src/demo.py --examples             # live demo (falls back to TF-IDF, and says so, if no transformer)
```

Training time of every run (measured on an RTX 5050 laptop GPU) is in `outputs/runs/*.json` and in the "Training runs"
table of `outputs/round2_results.md`. Without a local GPU use `notebooks/round2_colab.ipynb` with
`python src/make_colab_bundle.py`. CPU smoke test of the whole training path: `python src/train_transformer.py --smoke`.

| Config | Training data | Validation used for model selection |
|---|---|---|
| `A_english` | English (human-labelled) | English val |
| `B_translated` | + machine-translated Hindi/Bengali | English + translated val |
| `C_full` | + synthetic (LLM-generated) Hindi/Bengali | English + translated + synthetic val |

Models: `ai4bharat/IndicBERTv2-MLM-only` (main), `google/muril-base-cased` (comparison), TF-IDF + LogReg (baseline),
all on identical data. Input = (English claim, comment), max length 128; class-weighted cross-entropy, lr 2e-5,
batch 32, up to 5 epochs, 10% warmup, weight decay 0.01, fp16, seed 42. Test sets are never used for model selection.

### Indic preprocessing findings

1. Apply Unicode NFC first: Devanagari nukta letters have precomposed and decomposed encodings.
2. Repetition collapse acts on code points, not glyphs: `नहीीीीी` becomes `नहीी` because the vowel sign is a code point.
3. Python `\w` / scikit-learn's default tokenizer split Hindi words at vowel signs; we use an Indic-aware pattern.
4. Script ID from Unicode ranges separates Devanagari/Bengali but cannot tell Romanised Hindi from English.
5. `pandas.read_csv` turns the label string `"None"` into NaN; always `keep_default_na=False`.

## Next steps before the final evaluation

1. Check by hand, on 100 rows per language, that the stance label survives machine translation.
2. Annotate a small set of real public Hindi/Bengali comments as a genuine test set.
3. Several seeds per run; compare differences against the bootstrap intervals.
4. Target weak phenomena (sarcasm, implicit stance, Romanised text); add a zero-shot LLM baseline.
